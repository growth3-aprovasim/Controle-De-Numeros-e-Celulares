Regras de Automação do Webhook:
• Localização do Chip: Busca automaticamente pelo name (nome da conta) ou pelo number (telefone) cadastrado.
• Se motivo for "account-banned" (ou banido): O status do chip é alterado para Banido e o contador de Bans é incrementado.
• Se motivo for desconexão normal / logout: O status do chip é alterado para Reconectar.
